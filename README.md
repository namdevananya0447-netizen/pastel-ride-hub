# Pastel Wheels

Build a premium vehicle rental website frontend using React + Vite + Tailwind CSS.

Use a pastel aesthetic: sage green, mint, cream, peach and lavender. Clean, modern, minimal UI with rounded cards, soft shadows, smooth animations, premium vehicle images and responsive design.

Include:

Home: navbar, hero, booking search (pickup/drop-off/date/time), popular vehicles, offers, reviews.

Vehicle Search: filters (type, price, brand, fuel, transmission, seats, location), sorting and vehicle cards.

Vehicle Details: gallery, specs, features, reviews, availability calendar, transparent price breakdown and add-ons.

Booking: multi-step booking, KYC/license upload UI, UPI/card/wallet/net banking/pay-at-pickup and confirmation.

Dashboard: bookings, saved vehicles, profile, KYC, documents, payments and notifications.

Locations: map-style pickup locations.

Admin: fleet, bookings, pricing, maintenance and revenue.

Support: FAQ + chatbot UI.

Add standout features: Find My Ride quiz + match score, vehicle comparison, trip cost calculator, mood-based vehicle recommendations and EV Eco Score.

Routes: / /vehicles /vehicles/:id /booking /dashboard /locations /offers /find-my-ride /compare /trip-calculator /admin /support

Use realistic mock data and reusable components. Make Search → Vehicle → Booking → Confirmation the main polished flow. Keep it ready for future FastAPI integration.
